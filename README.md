# 🎮 Faithful 1.8 - Custom Edit

A customized version of the **Faithful 1.8** texture pack originally edited by **Defib**, based on **Vattic's Faithful x32**.  
This version includes visual and audio tweaks from various community packs to enhance the classic feel.

## 📦 Features & Credits

- **Base Pack**: Vattic's Faithful x32  
- **Previous Editor**: Defib  
- **Extra Textures**: Faithful Classic 1.19.4 x32 (Jappa)  
- **Water, Skies, Lightmap**: Hazza's Cookie Pack x16  
- **Bow Sound**: Birch Pack

> Made for personal use and shared with love for yall.  
> All rights belong to the original creators.

## 📥 Installation

1. Download the file of this texture pack.
2. Place it in your Minecraft `resourcepacks` folder.
3. Activate it in-game via **Options → Resource Packs**.

Enjoy!
